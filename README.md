> A modern, responsive, and feature-rich personal web portfolio built with React, TailwindCSS, Framer Motion, and Node.js.

---

## 🚀 Project Overview

This is **Ekramul Haque's personal portfolio website**, showcasing skills, projects, and contact information. The website is designed with a **dark modern theme**, with optional **light old-newspaper aesthetic** theme, offering:

- Hero section with animated typing effect.
- Project showcase with tabbed filtering.
- Skills section with categorized cards.
- Contact form for direct communication.
- Smooth scrolling and section highlighting.
- Fully responsive layout (desktop, tablet, mobile).
- Light/Dark theme toggle for aesthetic variation.

---

## 🌟 Features

### Hero Section
- Animated typing effect for role descriptions like *Full Stack Developer*, *React Developer*, *MERN Stack Developer*, etc.
- Highlighted name with gradient effect.
- CTA buttons for **Resume** download and **Projects** navigation.
- Floating glowing elements and hover animations for a modern look.

### About Section
- Professional introduction.
- Focus on modern development practices: clean code, responsive design, scalable architecture.

### Skills Section
- Showcases frontend & backend skills.
- Grid layout for better visualization.
- Hover effects for interactive feel.

### Projects Section
- Filterable projects (Web, Android, Vibe Web, Vibe Android).
- Project cards display name, description, tech stack, live link, and GitHub repo.
- Smooth animations with Framer Motion.

### Contact Section
- Fully responsive contact form.
- Input validation ready to integrate with backend or email API.
- CTA buttons for better UX.

### Navbar
- Sticky with scroll detection and section highlighting.
- Mobile-friendly hamburger menu.
- Smooth scroll to sections.
- Social links navigation.

### Footer
- Minimalistic footer with copyright.
- Optional links to social profiles.
